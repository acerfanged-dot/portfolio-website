## Notes for the next session

- **Vercel account structure, resolved this session, worth remembering:** the
  Hobby plan does not support real multi-person team collaboration at all (adding
  Kenny as a genuine collaborator on a shared "Talun Digital" team needs Pro,
  ~$20/seat/month) — verified against Vercel's own docs, not assumed. The operator
  chose to keep using Talun Digital's existing Vercel scope for personal projects
  too, accepting the blurred line, rather than pay for a properly separated
  structure right now. That's a deliberate, informed choice, not an oversight.
- **A Vercel GitHub-repo-not-found issue and its real fix**, in case it recurs:
  which repos show up in "Import Git Repository" depends on (a) which Vercel scope
  (personal vs. team) is currently selected, independent of which GitHub accounts
  are logged into the browser, and (b) whether the Vercel GitHub App's installation
  on the relevant GitHub account has that specific repo in its allowed list (if it's
  set to "only select repositories" rather than "all repositories"). Fix: while in
  the correct Vercel scope, GitHub account selector → "Adjust GitHub App
  Permissions" → add the repo.
- **Headless Chrome screenshot gotcha**, same one PEPPOOL's own handover notes
  already flagged from a different angle: a client-side-rendered page needs
  `--virtual-time-budget` (or equivalent) before `--screenshot`, or you capture
  whatever loading state happened to be on screen at that instant, not the real
  content.
- **This project's default branch is `master`**, while the gardening blog's is
  `main` — cosmetic inconsistency, noted but not fixed.
